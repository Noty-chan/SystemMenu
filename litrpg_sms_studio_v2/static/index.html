Создавай и редактируй системные окна
Выбери тип, настрой поля, двинь окно на холсте и экспортируй PNG — всё без сторонних фреймворков.
Клик — загрузить сцену с готовыми полями, позицией, FX и темой. Удобно, чтобы быстрее «завести» макет.
Вставка в активное поле. Метки — просто токены, удобны для шаблонов.
Вставляет готовые шаблоны: pill/tag и т.п.
Коррупция применяется только к текстовым зонам (не к ключам/числам), чтобы чтение оставалось возможным.
Можно быстро править: тип, тема, контент, позицию/размер, FX, темы/пресеты.
Тема
Сохраняется локально. Можно менять отступы/шрифты/орнаменты без правки файлов.
Перетаскивай окно за заголовок. Resize — за правый нижний угол. Двойной клик по заголовку: центр по X.
Экспорт PNG: «Окно» — прозрачный фон; «Холст» — со сценой. Для стабильного результата включи «Заморозить анимации при экспорте».

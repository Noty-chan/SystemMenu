## О проекте
- **LitRPG System Message Studio v2** — одностраничное веб‑приложение на FastAPI + ванильный JS/HTML/CSS. Сервер отдаёт статические файлы, а весь функционал (7 типов окон, темы, FX, экспорт PNG) реализован в `static/`.

## Правила разработки
- Всегда отвечайте на вопросы и пишите итоговые сообщения **только на русском**.
- Соблюдайте существующий стек: FastAPI для раздачи статики, без сторонних фронтенд‑фреймворков.
- Поддерживайте читаемость: понятные имена переменных/функций, компактные патчи без лишних зависимостей.
- Перед коммитом проверяйте запуск сервера (`python app.py`) и базовую работоспособность UI в браузере, если менялась логика фронтенда.

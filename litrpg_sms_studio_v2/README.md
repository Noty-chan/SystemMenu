# LitRPG System Message Studio v2 (MVP+)

Локальный редактор «системных окон» (ЛитРПГ) с темами, пресетами, эффектами «лаг/глич», расширенным форматированием и экспортом в PNG (высокое разрешение).

## Возможности
### 7 типов окон
1) Окно персонажа  
2) Уведомление системы (toast)  
3) Квест  
4) Логи  
5) Глобальное уведомление (баннер)  
6) Способность/класс  
7) Лут/награда  

### Темы и кастомизация
- Встроенные темы + создание своих (цвета/радиус/толщина рамки/тень/свечение).
- «Пользовательский CSS» (локально), чтобы править внешний вид без редактирования файлов проекта.

### Эффекты «лаг/глич»
- FX режимы: Нет / Лаг / Глич / Скан‑линии.
- Интенсивность (ползунок).
- «Коррупция текста» (ползунок) с сидом (фиксируемый/обновляемый).
- Опция «Заморозить анимации при экспорте» (чтобы PNG был предсказуемым).

### Форматирование текста
Поддерживается быстрыми кнопками и маркерами:
- **жирный**, _курсив_, ==акцент==, ~~зачёрк~~, ++подчёрк++, `код`
- Вставка блоков: [[pill:accent:Текст]], [[pill:warn:Текст]], [[tag:Текст]]

### Правки и переносимость
- Пресеты (тип+тема+контент+позиция/размер+FX).
- Экспорт/импорт JSON (темы + пресеты).
- «Редактор JSON текущего проекта» (можно быстро править руками).

## Запуск
1) Установка:
   pip install -r requirements.txt

2) Запуск сервера:
   python app.py

3) Открыть:
   http://127.0.0.1:8000

## Экспорт PNG
Экспорт делается в браузере через html2canvas.
Приложение пытается загрузить библиотеку:
1) локально: static/vendor/html2canvas.min.js
2) иначе — с CDN.

Если нужен полностью офлайн‑режим: скачай html2canvas (min) и положи в:
- static/vendor/html2canvas.min.js

## Структура
- static/index.html — разметка
- static/style.css — стили + FX
- static/app.js — логика, шаблоны окон, темы, пресеты
